## Dashboard — Decathlon Sales & Customer Analytics
Overview
This folder contains the Excel dashboard for the Decathlon Sales & Customer Analytics project. The dashboard is designed to summarise retail performance and make year-level comparisons easy through an interactive slicer.


KPI interpretation
- AOV (Average Order Value): generally calculated as total order sales divided by the number of orders. Confirm the exact field and formula used in the workbook before reusing the metric.
- YoY %: represents the percentage difference between the selected year and its comparison year. A positive value indicates an increase; a negative value indicates a decrease.
- Customer retention rate: use the definition implemented in the workbook. Retention can be calculated in different ways, so the displayed percentage should not be compared with another source unless the definitions match.

Workbook notes
- The dashboard is supported by data and analysis worksheets in the workbook, including Data, Insights, and Sportsimagetable.
- Some Excel features such as slicers, PivotTables, and linked chart objects may not behave identically in Google Sheets, LibreOffice, or web-based spreadsheet viewers.
- If the dashboard does not update as expected, use Excel's Data → Refresh All command and verify that the slicer is connected to the intended PivotTables.
