# Decathlon_Dashboard-Excel-
 ## Decathlon Sales & Customer Analytics
An Excel-based data analysis project that turns synthetic Decathlon retail transactions into an interactive sales and customer analytics dashboard.
Project overview.

This project analyses retail order data across 2024–2026 to explore sales performance, order volume, customer activity, average order value, product categories, sports types, customer retention, and gender-wise sales. The dashboard includes a Year slicer so users can filter the view and review year-specific performance.

Objectives
- Summarize sales and order performance using headline KPIs.
- Compare year-over-year (YoY) performance.
- Identify leading sports types and product categories.
- Explore monthly sales patterns.
- Review customer metrics and retention.
- Present findings in a clear, interactive Excel dashboard.
  
Dashboard features
- KPI cards: Total Sales, Total Orders, Total Customers, and Average Order Value (AOV).
- YoY comparisons: Percentage change indicators for key metrics.
- Top 5 sports types: Sales and order counts.
- Sales over time: Monthly trend chart.
- Sales by product category: Category-level comparison.
- Customer retention rate: Retention metric displayed with a monthly trend.
- Sales by gender: Comparison of sales by gender.
- Year slicer: Filters the dashboard by 2024, 2025, or 2026.

  
Tools and techniques
- Microsoft Excel
- Excel Tables and PivotTables
- PivotCharts and dashboard visual design
- Slicers and interactive filtering
- KPI and year-over-year calculations
- Data summarization and business insight generation


Key metrics shown in the dashboard
The complete dataset summary in the workbook's analysis sheet reports approximately:
- Total orders: 30,000
- Unique customers: 8,998
- Total sales: ₹36.7 Cr
- Average order value: approximately ₹12,236
These are calculated from the synthetic dataset and may differ from a filtered dashboard view. The dashboard's displayed values depend on the selected year and the workbook's calculation logic.
